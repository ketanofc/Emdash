Security & Transparency

How Emdash protects your prompts, files, and generated apps

Emdash is designed with minimal data retention by default. Build sessions, theme preferences, and daily usage counters remain in your browser, while preview code runs inside sandboxed iframes.

Sandboxed App Previews

Generated applications render inside isolated iframe containers so preview scripts cannot access parent session tokens or host DOM state.

Transport & API Security

All generation requests, uploaded reference assets, and live publish operations are transmitted over encrypted HTTPS connections and processed server-side without exposing provider keys in the browser.

Minimal Local Storage

Your theme setting, daily build quota, and optional local display profile reside in browser storage under your control and can be cleared anytime.

Vulnerability Reporting

Found a security issue or privacy concern? Email our security team directly at info@emdash.world for a prompt response.
